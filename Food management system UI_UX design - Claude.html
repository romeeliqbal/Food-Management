Architected interactive food management dashboard with distinctive design system

This is Larder — a full food/pantry management dashboard, built around one core idea: freshness as data, not decoration.

Design choices:

  • Freshness dials replace generic progress bars — each item gets a small ring gauge that fills and shifts color (moss green → turmeric → paprika rust) based on real days-to-expiry.
  • Stamped category tags (dashed border, slight rotation) echo produce-crate/grocery-label styling instead of flat pill badges.
  • Palette: sage linen background, deep moss ink, with the three freshness colors doing the only real "accent" work in the UI.
  • Type: Fraunces (serif, warm) for headings, Karla for body text, IBM Plex Mono for quantities and dates — giving stock numbers a stamped, ledger-like feel.

It's fully interactive:

  • Filter by category, search by name
  • Add new items via modal (auto-generates a dial)
  • Mark items "used" (tracks waste-reduction stats live)
  • "Use it up" recipe suggestions tied to expiring stock
  • Click any day in the week strip to plan a meal
  • Shopping list with add/check-off

Open the file in a browser to try it — happy to adjust the theme (e.g. restaurant/commercial-kitchen tone vs. home-pantry), add a dark mode, or turn this into a React component if that fits better with your other work.
